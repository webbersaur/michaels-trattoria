Recommended Action Plan

  1. Submit Sitemap to Google Search Console Google still has the old WordPress URLs indexed. Submit the new sitemap.xml via Google Search Console immediately so Google discovers and indexes the new pages. Also submit URL removal requests for the old WordPress URLs that no longer exist. Critical — fixes indexing On-site
  2. Optimize Google Business Profile Ensure GBP is fully complete: correct primary category ("Italian Restaurant"), add secondary categories ("Seafood Restaurant", "Catering Food and Drink Supplier", "Bar"), upload 20+ high-quality photos, add menu link to new website, write a keyword-rich business description, enable messaging, post weekly updates (specials, events). This controls whether you appear in the Map 3-pack. Highest impact for local search Off-site
  3. Launch a Review Strategy You have a 4.5 star rating which is excellent, but need more recent Google reviews specifically (Yelp reviews don't help Google rankings). Train staff to ask satisfied diners to leave a Google review. Create a short URL or QR code for the table. Respond to every review (positive and negative) within 24-48 hours. Target 5+ new Google reviews per month. Major ranking factor Off-site
  4. Claim & Optimize Directory Listings Ensure consistent NAP (Name, Address, Phone) across: TripAdvisor, Yelp, OpenTable, Facebook, Apple Maps, Bing Places, Foursquare, Yellow Pages, and CT-specific directories (CTvisit.com — already listed). Update all listings to link to the new website URL. Builds local authority Off-site
  5. Add Local Content to Website The homepage needs more Wallingford-specific text content. Add neighborhood references ("downtown Wallingford", "Center Street"), mention nearby landmarks, write about the restaurant's 30-year history in the community. Google rewards locally-relevant content for local searches. Consider adding a dedicated About page with the founder's story. Improves topical relevance Content
  6. Create a Dedicated Private Events Page Currently private events is just a section on the homepage. A standalone page targeting "private dining wallingford ct", "event venue wallingford ct" captures long-tail searches with high booking intent. Captures long-tail traffic On-site
  7. Build Local Backlinks Pursue links from: Wallingford Chamber of Commerce, local food bloggers, CT dining guides, wedding/event planning sites (for private dining), local news features, community sponsorships. Each quality local backlink strengthens domain authority. Long-term authority building Off-site
  8. Set Up 301 Redirects from Old URLs The old WordPress URLs (/dinner/, /lunch/, /about-us/, etc.) still show in Google's index. If possible, set up 301 redirects from the old paths to the new pages. This preserves any link equity from the old pages and prevents 404 errors for existing visitors. Preserves existing authority On-site
